# Client marks

Client credits on the Unreal Visualisation page are supplied by the site owner.

- `hyundai.svg`: official white Hyundai emblem, downloaded from
  https://www.hyundai.com/etc.clientlibs/hyundai-wwn3/clientlibs/main/resources/img/hyundai-logo-white.svg
- `world-triathlon.svg`: official World Triathlon wordmark, downloaded from
  https://triathlon.org/static-assets/images/svg/logo.svg
  The original black fill is white for the dark page; a viewBox was added for
  responsive sizing. The paths and proportions are unchanged.

Retrieved 2026-09-24. Marks identify the respective clients and remain their property.

- `reebok.svg`: original SVG from the supplied Reebok IMPACT project,
  `PNG/logo-reebok-header.b4ccbabf.svg`, preserved unchanged.
- `futureverse.svg`: FutureverseLogo vector paths and clipping geometry from
  Futureverse’s published `@futureverse/auth-ui` 1.0.7 package (dist/index.js).
  Inherited fill is set to warm white for this dark page.
  Source: https://registry.npmjs.org/@futureverse/auth-ui/-/auth-ui-1.0.7.tgz
